PolicyExperiments.xlsx: Excel raw data for the policy experiments reported in Bassart-i-Loré, M. (2026). Mixing innovation policies for low-carbon transitions? An agent-based approach. Technological Forecasting and Social Change, 222, Article 124372. https://doi.org/10.1016/j.techfore.2025.124372

pNK_structured_MC_grid_search.py: Python code enabling grid search in the parameter space.
pNK_structured_Sobol.py: Python code enabling a gloabl Sobol sensitivity analysis.
